# Llumnix OFF/ON 合并快测汇总

## 范围与方法

- 合并来源：低负载复测 QPS 0–5，以及 [原快测数据](../migration_crossover_20261020_120747/report.md)，覆盖 QPS 0、1、2、3、4、5、5.5675、8、10、12、16、20。
- 每档使用 seed 101；OFF/ON 复用同一 Poisson 请求轨迹。Balanced 迁移策略、4 个独立实例、模型、rayrpc 后端及其他运行参数一致。
- 除 QPS 0 外，每档测量 20 秒、预热 5 秒；所有请求在排空后均成功。QPS 0 是空闲控制，没有请求，所有请求时延指标记为 N/A。
- QPS 0–5 与原始 QPS 5.5675–20 是两次采集合并，属于单种子探索结果；不同时间启动的测量可能有运行间波动。迁移次数计入预热和测量阶段。
- “测量窗完成 QPS”统计测量窗口内完成的请求，不把排空阶段完成数当作稳态吞吐。
